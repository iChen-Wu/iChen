# 正式版更新指南

中枢新功能在**开发版**（`d:\workspace\iChen`）做好、测试通过后，用本指南的流程同步到
**正式版**（`D:\iChen`）。工具：工程台 `../workbench/tools/update_production.py`（仓库外）。

## 一、同步范围（只换中枢代码）

| 同步 | 内容 |
|---|---|
| ✅ 会更新 | `system/`（逐文件镜像：新增/修改/删除）、`main.py`、`README.md` |

| 永不触碰 | 原因 |
|---|---|
| 🚫 `apps/` | 正式版装的是用户日常使用的 App；工作区 apps 只是测试夹具，覆盖 = 丢 App |
| 🚫 `shared/` | 正式版业务库（BYu 等）与工作区分叉维护 |
| 🚫 `data/` | 业务数据库与配置（gyun_data.db、local_config.json、automation.json 等） |
| 🚫 `runtime/` | 正式版/移动版自带 Python 环境（若存在） |

这是工具里的硬编码保护，`--apply` 也不会改上述目录。

> 事故背景：V3 初期曾用「整目录覆盖」方式更新，正式版启动时发现库里没有新路径的业务数据库，
> 自动建了空库，导致业务数据"消失"（2026-10-04，已恢复）。此后更新只允许换代码。

## 二、标准流程

```bash
# 0. 在工作区确保测试全绿
python ../workbench/tools/run_tests.py

# 1. 更新前备份正式版业务库（重要，见《数据与备份说明》）
copy D:\iChen\data\db\gyun_data.db ^
     D:\iChen\data\db\backups\gyun_data_before_update_YYYYMMDD.db

# 2. 只比对，看变更清单（默认行为，绝不写入）
python ../workbench/tools/update_production.py

# 3. 确认清单无误后执行
python ../workbench/tools/update_production.py --apply

# 4. 再跑一次比对，应显示「无差异」
python ../workbench/tools/update_production.py
```

工具行为：

- 按文件 SHA-256 哈希比对，列出 **新增 / 修改 / 删除**；
- `system/` 是纯代码目录，源端删除的文件会在目标端同步删除（保持镜像）；
- 目标不像 iChen（缺 `system/` 或 `main.py`）时拒绝执行；
- `--apply` 写入后自动复核哈希，仍有差异会报警。

## 三、更新后验证

1. 启动正式版（iChen.lnk），桌面正常、托盘在；
2. 打开 1~2 个业务 App（如班级管理），确认历史数据还在；
3. 涉及界面改动时切换一次深浅色主题；
4. 涉及后台服务时到「控制台 → 后台」确认服务能起、端口正常。

发现问题：本次更新只动了 `system/` 和 `main.py`，把这两个位置从备份还原即可（数据不受影响）。

## 四、什么时候不能只走本工具

- **改了 `shared/`**（GYun / BYu / common）：本工具不同步 shared。正式版 shared 是业务环境，
  需单独评估——先在正式版备份对应文件，再手工拷贝**代码文件**（绝不拷贝任何 data/runtime 下的
  数据库），然后启动验证；数据库结构变更必须配套迁移逻辑。
- **新增了第三方依赖**：正式版用系统 Python，需要在正式版环境手工 `pip install`；
  移动版依赖安装见工程台 `../workbench/tools/install_runtime_deps.py` 的流程（禁止在 U 盘上直接 pip）。
- **移动版 F:\iChen**：可 `python ../workbench/tools/update_production.py F:/iChen --check` 比对，
  但 U 盘写入不可靠（FAT32 曾出现整文件变 null 字节），写入后必须核对文件大小与哈希；
  稳妥做法仍是 D 盘暂存 + robocopy 顺序写入。

## 五、工具位置与维护

- 脚本位置：仓库外工程台 `../workbench/tools/update_production.py`（不在 git 仓库内）。
- 保护清单（`PROTECTED`）与同步清单（`SYNC_DIRS / SYNC_FILES`）都在脚本顶部常量区，
  规则变更时改这里并同步更新本文档。
